# CMPA 4303 Web Project Repository

## What is this?
This project is a functional, live-deployed web project built for CMPA 4303. It serves as a milestone implementation demonstrating layout structure, responsive design, and core interactive functionality hosted via GitHub Pages.

## Why does it exist?
The purpose of this milestone is to transition the project from local development to a live environment, establishing a stable baseline of real content, visual coherence, and working user interactions.

## What tools did I use?
* **Visual Studio Code & GitHub Desktop:** Used for local editing, version control, and managing commits.
* **GitHub & GitHub Pages:** Used for continuous integration and instant static deployment.
* **HTML/CSS & JavaScript:** Chosen to build structural layouts, responsive styling, and core interactive elements.

You can view the live deployed project here: https://iochei.github.io/CMPA-4303-Repository/
